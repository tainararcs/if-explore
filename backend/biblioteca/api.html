biblioteca.py

Consulta o acervo da biblioteca do campus em Python. O catálogo roda em PHL Elysio, que não tem API: este módulo conversa com a interface HTTP do próprio catálogo e entrega objetos Python com tipos previsíveis. Um arquivo só, sem dependências.

from biblioteca import Biblioteca

bib = Biblioteca("https://biblioteca.barbacena.ifsudestemg.edu.br")

for livro in bib.buscar(titulo="python", ano=(2019, 2024)):
    print(livro)

Regras da API

Valem para todas as chamadas, então você não precisa decorar caso a caso.

SituaçãoO que acontece
Um livro (bib.livro)Devolve Livro, ou None se não existir. Nunca levanta "não encontrado".
Uma busca (bib.buscar)Devolve Resultado, que é uma lista. Vazia se nada foi achado.
Argumento inválidoValueError, dizendo o que é aceito.
URL errada ou servidor fora do arBibliotecaError (ou ErroDeConexao, que é subclasse).

Privacidade. A tela do catálogo mostra a matrícula de quem está com o livro emprestado. Esse dado não existe nesta API: Exemplar não tem campo de usuário, e nada em Livro o carrega.

Gentileza com o servidor. É um CGI do campus, que sobe um processo por requisição. O padrão é 0,5 s de pausa entre chamadas e cache de 120 s. Tudo marcado com consulta o servidor custa uma requisição; o que é local é cálculo em memória.

Biblioteca()

O ponto de entrada. Criar o objeto já abre uma sessão no catálogo.

Biblioteca(url, *, pausa=0.5, timeout=60, cache=120, conectar=True)
ParâmetroTipoO que faz
urlstrO site do catálogo (https://biblioteca.exemplo.br) ou a URL completa que o navegador mostra, com ?IsisScript=phl82.xis&…. Só com o site, a versão dos scripts é descoberta sozinha.
pausafloatSegundos de espera entre requisições. Baixe com cuidado: o servidor é compartilhado.
timeoutintSegundos até desistir de uma requisição.
cacheintPor quantos segundos uma resposta idêntica fica guardada. 0 desliga.
conectarboolFalse adia a conexão até a primeira consulta.

Atributo

bib.phlPHLO cliente de baixo nível, para o que esta API não cobre: busca crua, índices, prefixos ISIS, referências em lote.

.buscar() consulta o servidor

Busca por critérios combinados. Todos os critérios informados precisam valer ao mesmo tempo.

bib.buscar(texto=None, *, titulo=None, autor=None, assunto=None, editora=None, isbn=None, ano=None, curso=None, area=None, classificacao=None, tipo=None, idioma=None, expressao=None, limite=50) -> Resultado

Critérios de texto

Procuram todas as palavras, sem diferença de acento ou maiúscula. A pontuação é ignorada, então "Fowler, Martin" e "Martin Fowler" dão o mesmo resultado.

ParâmetroProcura em
textoQualquer campo, como a caixa de busca do site. Use este para uma caixa livre, onde a pessoa pode digitar título e autor juntos.
tituloSó no título e subtítulo.
autorSó nos campos de autoria.
assuntoSó nos descritores de assunto.
editoraSó no campo de editora.

Outros critérios

ParâmetroAceitaObservação
isbnstr | intCom ou sem hífen, ISBN-10 ou 13. O catálogo mistura os formatos; a API converte e procura todas as formas.
anoint | tupla2021 ou (2019, 2024). É o ano de publicação. O servidor não sabe buscar por ele, então o filtro é feito aqui: usar ano sozinho baixa o acervo inteiro (~10 s).
cursostr | intCódigo do curso cuja bibliografia inclui o livro (ex.: 24). O servidor não publica os nomes dos cursos.
areastr | intÁrea do conhecimento (CNPq): o número 1–9 ou o nome, como "engenharias". Ver valores aceitos.
classificacaostrCDD por prefixo: "005" traz 005, 005.1, 005.133…
tipostr"livro", "periodico", "tese", "e-book"… Ver valores aceitos.
idiomastr | int"portugues", "ingles"… ou o código 1–9.
expressaostrExpressão ISIS crua, para E/OU/EXCETO: "PYTHON + JAVA", "MATEMATICA ^ ALGEBRA". Aqui + é OU e ^ é EXCETO.
limiteint | NoneMáximo de livros. Padrão 50; None traz todos. O corte nunca é silencioso: veja .truncado.

A ordem não é por relevância. O catálogo devolve na ordem dele. Nunca use o primeiro resultado como "o melhor": mostre vários, ou ordene você mesmo com sorted().

.livro() consulta o servidor

Busca um livro específico. Informe exatamente um dos três identificadores.

bib.livro(id=None, *, isbn=None, tombo=None) -> Livro | None
ParâmetroO que é
idCódigo do título no catálogo, o que aparece em livro.id.
isbnCom ou sem hífen, ISBN-10 ou 13.
tomboNúmero de tombo do exemplar, o da etiqueta colada no livro.

Devolve None se não existir. Informar nenhum ou mais de um levanta ValueError.

.novidades() consulta o servidor

bib.novidades(desde=None, ate=None) -> Resultado
  • Sem argumentos: o feed "Aquisições do Mês" do próprio catálogo.
  • Com desde (e ate, que por padrão é hoje): registros que entraram no catálogo no período, do mais novo para o mais antigo.

As datas aceitam "AAAA-MM-DD", "DD/MM/AAAA" ou um objeto date. Registros cuja data de entrada não é uma data válida ficam de fora.

.sugerir() consulta o servidor

bib.sugerir(termo) -> list[str]

O "você quis dizer?": devolve entradas do índice do catálogo parecidas com o termo, ou uma lista vazia. Cobre erro no fim da palavra ("algoritmoss" → ALGORITMOS), não no meio de uma frase. Serve também como autocompletar.

Livro

Os tipos são previsíveis: as listas são sempre listas, mesmo com um item só ou nenhum; os números são int ou None; texto que falta é None. Você não precisa tratar caso a caso.

Situação dos exemplares consulta o servidor

Buscados na primeira vez que você lê qualquer um deles, e guardados no objeto: ler os cinco custa uma requisição, não cinco.

exemplareslist[Exemplar]Um por cópia física.
disponivelboolSe há pelo menos um exemplar livre agora.
disponiveisintQuantos exemplares estão livres.
emprestimosintTotal de empréstimos já feitos, somando os exemplares. Só o total: o catálogo não guarda datas nem quem pegou.
referenciastr | NoneReferência bibliográfica pronta, gerada pelo próprio catálogo.

Métodos

livro.para_dict()dictPronto para JSON. Com exemplares=True inclui a situação, disponiveis e emprestimos rede.
livro.ficha()strTudo sobre o livro em texto, para imprimir rede.

Exemplar

Uma cópia física. Não guarda quem está com ela.

AtributoTipoConteúdo
tombostrNúmero de tombo, o da etiqueta.
etiquetastrTexto da etiqueta de lombada.
situacaostrdisponivel, emprestado, consulta_local, indisponivel ou reservado.
disponivelboolAtalho para situacao == "disponivel".
devolucaodate | NoneQuando volta, se estiver emprestado.
emprestimosintQuantas vezes este exemplar já foi emprestado.
renovacoesintQuantas renovações.
observacaostr | NoneObservação do exemplar, quando o catálogo traz.

Resultado

É uma list de Livro: dá para iterar, indexar e usar len() normalmente. Tem dois extras.

AtributoTipoConteúdo
totalintQuantos livros atendem à busca no acervo todo.
truncadoboolTrue se o limite deixou livros de fora. É assim que você sabe que há mais.

Métodos

resultado.tabela(colunas=("titulo", "autores", "ano", "editora"), largura=60) -> str resultado.salvar(caminho) -> Path
  • tabela() monta uma tabela Markdown. As colunas são atributos de Livro; uma coluna desconhecida levanta ValueError. Colunas como disponiveis consultam o servidor, uma requisição por livro.
  • salvar() grava .csv (abre no Excel) ou .json, conforme a extensão do nome.

Atenção: fatiar (resultado[:10]) devolve uma list comum, que não tem total nem truncado.

Erros

ExceçãoQuando
ValueErrorArgumento inválido: ano fora de faixa, tipo desconhecido, ISBN com número errado de dígitos, busca sem nenhum critério.
BibliotecaErrorProblema com o catálogo: URL que não é um PHL, ou resposta de erro do servidor.
ErroDeConexaoServidor inacessível, sem resposta ou com erro HTTP. É subclasse de BibliotecaError, então except BibliotecaError pega os dois.

Limitações conhecidas

  • Não dá para buscar C++. O + é operador OU no motor do catálogo e não há como escapá-lo. C# funciona.
  • Sem ordenação por relevância. O catálogo não tem esse conceito.
  • Empréstimos só em total. Não há datas nem histórico por pessoa.
  • Nomes de cursos não são publicados pelo servidor, só os códigos.
  • Disponibilidade custa uma requisição por livro. Para listas grandes, filtre antes e consulte depois.

Exemplo · Buscar no acervo

from biblioteca import Biblioteca
bib = Biblioteca("https://biblioteca.barbacena.ifsudestemg.edu.br")

# caixa de busca livre: use texto=, que procura em todos os campos
r = bib.buscar(texto="algoritmos cormen")
print(len(r), "de", r.total, "| truncado:", r.truncado)

# busca por campo, combinando critérios (os dois precisam valer)
r = bib.buscar(titulo="python", ano=(2019, 2024))
print(r.tabela(("titulo", "autores", "ano", "isbn"), largura=34))

for livro in r[:3]:                 # 1 requisição por livro consultado

        print("%-46s %d de %d livre(s) — %s" % (

Exemplo · Tratar erros

from biblioteca import Biblioteca, BibliotecaError

try:
    bib = Biblioteca(url_do_catalogo)
    r = bib.buscar(titulo=termo_digitado, tipo=tipo_escolhido)
except ValueError as e:
    print("Confira o que foi digitado:", e)     # a mensagem diz o que é aceito
except BibliotecaError as e:
    print("O catálogo não respondeu:", e)      # inclui ErroDeConexao

Documentação da API para uso final. O módulo é um arquivo só, biblioteca.py, sem dependências além da biblioteca padrão do Python. Para o que esta API não cobre — busca crua, índices de autoridade, prefixos ISIS, referências em lote — use bib.phl.
