phl_client

Consulta o acervo da biblioteca do campus em Python. O catálogo roda em PHL Elysio, que não tem API: este pacote conversa com a interface HTTP do próprio catálogo e entrega objetos Python com tipos previsíveis. Só usa a biblioteca padrão.

from phl_client import Library

library = Library("https://biblioteca.barbacena.ifsudestemg.edu.br")

for book in library.search(title="python", year=(2019, 2024)):
    print(book)

Regras da API

Valem para todas as chamadas, então você não precisa decorar caso a caso.

SituaçãoO que acontece
Um livro (library.book)Devolve Book, ou None se não existir. Nunca levanta "não encontrado".
Uma busca (library.search)Devolve SearchResult, que é uma lista. Vazia se nada foi achado.
Argumento inválidoValueError, dizendo o que é aceito.
URL errada ou servidor fora do arLibraryError (ou LibraryConnectionError, que é subclasse).

Privacidade. A tela do catálogo mostra a matrícula de quem está com o livro emprestado. Esse dado não existe na API pública: Copy não tem campo de usuário, e nada em Book o carrega. Só o cliente de baixo nível o devolve, e apenas com include_borrower=True.

Gentileza com o servidor. É um CGI do campus, que sobe um processo por requisição. O padrão é 0,5 s de pausa entre chamadas e cache de 120 s. Tudo marcado com consulta o servidor custa uma requisição; o que é local é cálculo em memória.

Library()

O ponto de entrada. Criar o objeto já abre uma sessão no catálogo.

Library(url, *, pause=0.5, timeout=60, cache=120, connect=True)
ParâmetroTipoO que faz
urlstrO site do catálogo (https://biblioteca.exemplo.br) ou a URL completa que o navegador mostra, com ?IsisScript=phl82.xis&…. Só com o site, a versão dos scripts é descoberta sozinha.
pausefloatSegundos de espera entre requisições. Baixe com cuidado: o servidor é compartilhado.
timeoutintSegundos até desistir de uma requisição.
cacheintPor quantos segundos uma resposta idêntica fica guardada. 0 desliga.
connectboolFalse adia a conexão até a primeira consulta.

Atributo

library.phlPhlClientO cliente de baixo nível, para o que esta API não cobre: busca crua, índices, prefixos ISIS, referências em lote, exportação do acervo inteiro (search_all).

.search() consulta o servidor

Busca por critérios combinados. Todos os critérios informados precisam valer ao mesmo tempo.

library.search(text=None, *, title=None, author=None, subject=None, publisher=None, isbn=None, year=None, course=None, area=None, classification=None, document_type=None, language=None, expression=None, limit=50) -> SearchResult

Critérios de texto

Procuram todas as palavras, sem diferença de acento ou maiúscula. A pontuação é ignorada, então "Fowler, Martin" e "Martin Fowler" dão o mesmo resultado.

ParâmetroProcura em
textQualquer campo, como a caixa de busca do site. Use este para uma caixa livre, onde a pessoa pode digitar título e autor juntos.
titleSó no título e subtítulo.
authorSó nos campos de autoria.
subjectSó nos descritores de assunto.
publisherSó no campo de editora.

Outros critérios

ParâmetroAceitaObservação
isbnstrCom ou sem hífen, ISBN-10 ou 13. O catálogo mistura os formatos; a API converte e procura todas as formas.
yearint | tuple2021 ou (2019, 2024). É o ano de publicação. O servidor não sabe buscar por ele, então o filtro é feito aqui: usar year sozinho baixa o acervo inteiro (~10 s).
coursestr | intCódigo do curso cuja bibliografia inclui o livro (ex.: 24). O servidor não publica os nomes dos cursos.
areastr | intÁrea do conhecimento (CNPq): o número 1–9 ou o nome, como "engenharias". Ver valores aceitos.
classificationstrCDD por prefixo: "005" traz 005, 005.1, 005.133…
document_typestr"book", "periodical", "thesis", "ebook"… Ver valores aceitos.
languagestr | int"portugues", "ingles"… ou o código 1–9.
expressionstrExpressão ISIS crua, para E/OU/EXCETO: "PYTHON + JAVA", "MATEMATICA ^ ALGEBRA". Aqui + é OU e ^ é EXCETO.
limitint | NoneMáximo de livros. Padrão 50; None traz todos. O corte nunca é silencioso: veja .truncated.

A ordem não é por relevância. O catálogo devolve na ordem dele. Nunca use o primeiro resultado como "o melhor": mostre vários, ou ordene você mesmo com sorted().

.book() consulta o servidor

Busca um livro específico. Informe exatamente um dos três identificadores.

library.book(book_id=None, *, isbn=None, accession_number=None) -> Book | None
ParâmetroO que é
book_idCódigo do título no catálogo, o que aparece em book.id.
isbnCom ou sem hífen, ISBN-10 ou 13.
accession_numberNúmero de tombo do exemplar, o da etiqueta colada no livro.

Devolve None se não existir. Informar nenhum ou mais de um levanta ValueError.

.new_arrivals() consulta o servidor

library.new_arrivals(since=None, until=None) -> SearchResult
  • Sem argumentos: o feed "Aquisições do Mês" do próprio catálogo.
  • Com since (e until, que por padrão é hoje): registros que entraram no catálogo no período, do mais novo para o mais antigo.

As datas aceitam "AAAA-MM-DD", "DD/MM/AAAA" ou um objeto date. Registros cuja data de entrada não é uma data válida ficam de fora.

.suggest() consulta o servidor

library.suggest(term) -> list[str]

O "você quis dizer?": devolve entradas do índice do catálogo parecidas com o termo, ou uma lista vazia. Cobre erro no fim da palavra ("algoritmoss" → ALGORITMOS), não no meio de uma frase. Serve também como autocompletar.

SearchResult

É uma list de Book: dá para iterar, indexar e usar len() normalmente. Tem dois extras.

AtributoTipoConteúdo
totalintQuantos livros atendem à busca no acervo todo.
truncatedboolTrue se o limit deixou livros de fora. É assim que você sabe que há mais.

Métodos

result.to_markdown(columns=("title", "authors", "year", "publisher"), width=60) -> str result.save(path) -> Path
  • to_markdown() monta uma tabela Markdown. As colunas são atributos de Book; uma coluna desconhecida levanta ValueError. Colunas como available_count consultam o servidor, uma requisição por livro.
  • save() grava .csv (abre no Excel) ou .json, conforme a extensão do nome.

Atenção: fatiar (result[:10]) devolve uma list comum, que não tem total nem truncated.

Erros

ExceçãoQuando
ValueErrorArgumento inválido: ano fora de faixa, tipo desconhecido, ISBN com número errado de dígitos, busca sem nenhum critério.
LibraryErrorProblema com o catálogo: URL que não é um PHL, ou resposta de erro do servidor.
LibraryConnectionErrorServidor inacessível, sem resposta ou com erro HTTP. É subclasse de LibraryError, então except LibraryError pega os dois.

Módulos e testes

Cada módulo só depende dos anteriores. Os de local não usam a rede.

MóduloResponsabilidade
errorsLibraryError e LibraryConnectionError.
fieldsTabelas do PHL: nomes dos campos, códigos de área, idioma, suporte, tipo e situação local.
text, isbn, queryFunções puras de texto, ISBN, URL do catálogo e preparo das buscas local.
parsersPáginas do OPAC → registros, exemplares e referências local.
transportSessão, HTTP em ISO-8859-1, cache e pausa.
clientPhlClient: buscas de baixo nível, exemplares, referências e índices.
modelsCopy, Book e SearchResult.
libraryLibrary, a fachada documentada acima.

Os testes não usam a rede: páginas reais do OPAC ficam em tests/fixtures/. Rode a partir de backend/:

python -m unittest discover -s phl_client/tests -t .

Limitações conhecidas

  • Não dá para buscar C++. O + é operador OU no motor do catálogo e não há como escapá-lo. C# funciona.
  • Sem ordenação por relevância. O catálogo não tem esse conceito.
  • Empréstimos só em total. Não há datas nem histórico por pessoa.
  • Nomes de cursos não são publicados pelo servidor, só os códigos. A exceção são os TCCs, que trazem o nome do curso em tcc_course.
  • Disponibilidade custa uma requisição por livro. Para listas grandes, filtre antes e consulte depois.

Exemplo · Buscar no acervo

from phl_client import Library
library = Library("https://biblioteca.barbacena.ifsudestemg.edu.br")

# caixa de busca livre: use text=, que procura em todos os campos
result = library.search(text="algoritmos cormen")
print(len(result), "de", result.total, "| truncado:", result.truncated)

# busca por campo, combinando critérios (os dois precisam valer)
result = library.search(title="python", year=(2019, 2024))
print(result.to_markdown(("title", "authors", "year", "isbn"), width=34))

Documentação da API para uso final. O pacote phl_client não tem dependências além da biblioteca padrão do Python. Para o que esta API não cobre — busca crua, índices de autoridade, prefixos ISIS, referências em lote — use library.phl.
